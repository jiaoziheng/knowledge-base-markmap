# 第十一章 常数项级数

## 10.1

### 一、级数的概念

#### 级数的定义
- 常数项无穷级数：Σuₙ = u₁ + u₂ + u₃ + … + uₙ + …
- uₙ：级数的一般项

#### 级数的部分和
- Sₙ = u₁ + u₂ + … + uₙ

#### 级数的收敛与发散
- 若 lim Sₙ = s，则级数 Σuₙ 收敛
- s 称为级数的和
- 若 lim Sₙ 不存在，则级数 Σuₙ 发散

### 二、级数的基本性质

#### 线性性质

##### 常数倍性质
- 若 Σuₙ 收敛，则 Σkuₙ 也收敛
- 每一项乘非零常数，不改变敛散性

##### 加减性质
- 若 Σuₙ、Σvₙ 都收敛，则 Σ(uₙ + vₙ)、Σ(uₙ - vₙ) 都收敛

#### 有限项性质
- 去掉有限项不改变敛散性
- 增加有限项不改变敛散性

#### 加括号性质
- 收敛级数加括号后仍收敛
- 级数和不变
- 注意：去括号后不一定收敛

### 三、级数收敛的必要条件

#### 必要条件
- 若 Σuₙ 收敛，则 lim uₙ = 0

#### 重要反推
- 若 lim uₙ ≠ 0，则 Σuₙ 发散

#### 易错点
- 必要条件不充分：lim uₙ = 0 不能推出 Σuₙ 收敛

#### 典型反例
- 调和级数：Σ1/n
- 虽然 lim 1/n = 0
- 但调和级数发散
