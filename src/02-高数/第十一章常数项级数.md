# 第十一章 常数项级数

## 一、级数的概念

### 级数的定义

- 常数项无穷级数：Σuₙ = u₁ + u₂ + u₃ + … + uₙ + …
- uₙ：级数的一般项

### 级数的部分和

- Sₙ = u₁ + u₂ + … + uₙ
- 也可写成：Sₙ = Σuᵢ，i 从 1 到 n

### 级数的收敛与发散

- 若 lim Sₙ = s，则级数 Σuₙ 收敛
- s 称为级数的和
- 若 lim Sₙ 不存在，则级数 Σuₙ 发散

## 二、级数的基本性质

### 常数倍性质

- 若 Σuₙ 收敛，则 Σkuₙ 也收敛
- 每一项乘非零常数，不改变敛散性

### 加减性质

- 若 Σuₙ、Σvₙ 都收敛
- 则 Σ(uₙ + vₙ)、Σ(uₙ - vₙ) 都收敛

### 有限项性质

- 去掉有限项不改变敛散性
- 增加有限项不改变敛散性

### 加括号性质

- 收敛级数加括号后仍收敛
- 级数和不变
- 注意：去括号后不一定收敛

## 三、级数收敛的必要条件

### 必要条件

- 若 Σuₙ 收敛，则 lim uₙ = 0

### 重要反推

- 若 lim uₙ ≠ 0，则 Σuₙ 发散

### 易错点

- lim uₙ = 0 不能推出 Σuₙ 收敛
- 必要条件不充分

### 典型反例

- 调和级数：Σ1/n
- 虽然 lim 1/n = 0
- 但调和级数发散

## 四、典型题型：判断敛散性

### 利用部分和判断

- 求出部分和 Sₙ
- 再判断 lim Sₙ 是否存在
- 存在则收敛
- 不存在则发散

### 利用一般项极限判断

- 先求 lim uₙ
- 若 lim uₙ ≠ 0，则直接发散

### 对数裂项型

- 典型形式：Σ ln[n/(n+1)]
- 利用 ln[n/(n+1)] = ln n - ln(n+1)
- 部分和会发生相消
- 最后看 lim Sₙ

### 利用调和级数

- 调和级数 Σ1/n 发散
- 遇到与 1/n 类似的形式要注意

## 五、本节核心结论

### 核心结论

- 级数是否收敛，看部分和数列 Sₙ 是否有极限
- Σuₙ 收敛 ⇔ lim Sₙ 存在
- Σuₙ 发散 ⇔ lim Sₙ 不存在
- Σuₙ 收敛 ⇒ lim uₙ = 0
- lim uₙ ≠ 0 ⇒ Σuₙ 发散
- lim uₙ = 0 不能推出 Σuₙ 收敛
- 调和级数 Σ1/n 发散
- 有限项增减不改变敛散性
- 收敛级数加括号后仍收敛
