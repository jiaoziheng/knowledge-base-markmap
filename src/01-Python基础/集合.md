# Python 集合 (Set)

## 一、集合基础概念
### 定义
- 无序的不重复元素序列
- 0个或多个对象引用的无序组合

### 三大特点
- **不同元素组成** — 自动去重
- **无序** — 没有索引，无法下标访问
- **元素必须是不可变类型** — 数字/字符串/元组可，列表/字典不可

### 表示方式
- 用花括号 { } 括起来

---

## 二、集合的创建
### 创建空集
- `set()` → 创建空集合
- `{}` → 创建的是空字典，**不是空集！**

### 从字符串创建
```python
ss = set('abcd')
# 结果: {'a', 'c', 'b', 'd'}
```

### 从列表创建
```python
ss1 = set([1, 2, 3])
# 结果: {1, 2, 3}
```

### 自动去重特性
```python
ss2 = set([1, 1, 2, 2, 3, 3])
# 结果: {1, 2, 3}  ← 重复元素自动过滤
```

---

## 三、集合操作
### 添加元素
- `集合.add(元素)` — 单个添加
- `集合.update(序列)` — 批量添加

### 删除元素
- `集合.remove(元素)` — 删除，不存在则报错
- `集合.discard(元素)` — 删除，不存在不报错
- `集合.pop()` — 随机删除一个

---

## 四、集合运算
### 四个基本运算
- `A | B` — 并集（合在一起）
- `A & B` — 交集（共同部分）
- `A - B` — 差集（A有B没有）
- `A ^ B` — 对称差集（不重复的部分）

---

## 五、集合方法速查
| 方法 | 作用 |
|------|------|
| add() | 添加单个元素 |
| update() | 批量添加 |
| remove() | 删除（不存在报错）|
| discard() | 删除（不存在不报错）|
| pop() | 随机删除一个 |
| clear() | 清空集合 |
| copy() | 浅拷贝 |
| union() | 并集 |
| intersection() | 交集 |
| difference() | 差集 |

---

## 六、易错提醒
- `{}` 创建空字典，`set()` 创建空集合
- 集合元素必须不可变（数字/字符串/元组可，列表/字典不可）
- 集合去重是自动的，但会改变原始顺序
