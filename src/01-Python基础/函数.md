# Python 第六章：函数

## 6.1 函数定义

### 基本语法

```python
def 函数名(参数1, 参数2, ..., 参数n):
    语句1
    语句2
    ...
    return 返回值
```

### 函数调用

```python
函数名(参数)
```

### 例：判断素数

```python
def isPrime(n):
    if n == 0 or n == 1:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    else:
        return True
```

#### 输出100以内所有素数

```python
for i in range(2, 101):
    if isPrime(i):
        print(i, end=' ')
```

#### 判断输入数字是否为素数

```python
m = int(input("请输入一个正整数："))
if isPrime(m):
    print(m, "是素数")
else:
    print(m, "不是素数")
```

## 6.2 参数的传递方式

### 6.2.1 位置参数

#### 特点

- 实参与形参数量一致
- 位置必须对应

#### 示例

```python
def calFunc(x, y, z):
    return 2*x + 3*y + 4*z
print(calFunc(10, 20, 30))
print(calFunc(20, 30, 10))
print(calFunc(30, 20, 10))
```

#### 错误情况

```python
print(calFunc(10, 20))
# 缺少参数
print(calFunc(10, 20, 30, 40))
# 参数过多
```

### 6.2.2 默认值参数

#### 特点

- 参数有默认值
- 调用时可省略

#### 示例

```python
def calFunc(x, y, z=30):
    return 2*x + 3*y + 4*z
print(calFunc(10, 20))
print(calFunc(20, 30))
print(calFunc(10, 20, 40))
```

#### 注意

- 无默认值参数放前面
- 默认值参数放后面

### 6.2.3 关键字参数

#### 特点

- 不受参数顺序限制
- 按参数名传值

#### 示例

```python
def calFunc(x, y, z):
    return 2*x + 3*y + 4*z
print(calFunc(10, 20, 30))
print(calFunc(z=30, x=10, y=20))
```

### 6.2.4 可变长度参数

#### *args

##### 特点

- 接收任意多个位置参数
- 本质是元组(tuple)

##### 示例

```python
def calScore(math, eng, coding, *optional):
    compulsory = math + eng + coding
    avg_optional = sum(optional) / len(optional)
    return int((compulsory + avg_optional) / 4)
```

##### 调用

```python
print(calScore(81, 95, 76, 90))
print(calScore(61, 57, 41, 75, 80, 68))
print(calScore(97, 95, 93, 95, 88))
```

## 6.3 变量的作用域

### 6.3.1 局部变量

#### 特点

- 函数内部定义
- 函数外不可访问

#### 示例

```python
x = 'abc'
def funca():
    x = 5
    return x * x
print(funca())
print(x)
```

### 6.3.2 全局变量

#### 方式1：函数外定义

```python
x = 'abc'
```

#### 方式2：global关键字

```python
x = 'ab'
def mo():
    global x
    x = 20
    return x
print(mo())
print(x)
```

#### 作用

- 在函数内部修改全局变量

## 6.4 Lambda函数

### 特点

- 匿名函数
- 一条语句完成
- 临时调用

### 语法

```python
lambda 参数: 表达式
```

### 示例

```python
f = lambda x, y, z: 2*x + 3*y + 4*z
print(f(10, 20, 30))
```

### 输出

```python
200
```

## 6.5 递归函数

### 特点

- 函数调用自身
- 必须有结束条件

### 阶乘示例

#### 数学定义

```text
n! = n × (n-1)!
1! = 1
```

#### 代码实现

```python
def fac(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * fac(n - 1)
m = int(input("m="))
print(fac(m))
```

#### 递归三要素

- 递归函数自身调用
- 递归终止条件
- 每次递归向终止条件靠近
