# Python 函数

## 一、函数定义语法
### 基本结构
- def 函数名(参数1, 参数2, ...):
-     语句1
-     return语句（可选）

### 语法规则
- **def** — 关键词，来自 define 缩写
- **函数名** — 遵循标识符命名规则（小写+下划线）
- **参数** — 圆括号内，逗号分隔
- **缩进** — 必须保持空格式（Python语法要求）
- **return** — 可选，决定有无返回值

---

## 二、函数调用语法
### 基本结构
- 函数名(参数1, 参数2, ...参数n)

### 调用特点
- 有返回值 → 可参与表达式运算
- 无返回值 → 单独作为语句使用

---

## 三、return 语句规则
### 核心规则
- 可出现在函数体任何位置
- 函数可有0条或多条return
- **首条执行的return** → 函数立即结束，返回值
- 无return语句的函数默认返回 None

### 返回值处理对比
| 类型 | 处理方式 |
|------|---------|
| 有返回值 | 交给主程序继续处理 |
| 无返回值 | 直接在函数内打印/单独使用 |

---

## 四、函数参数
### 形式参数 vs 实际参数
- 形式参数：定义时的参数名
- 实际参数：调用时传入的值

### 常见参数类型
- **位置参数** — 按顺序一一对应
- **默认参数** — 有默认值的参数（放最后）
- **关键字参数** — name=value 形式，不受顺序影响
- **不定长参数** — *args（接收元组）/ **kwargs（接收字典）

---

## 五、函数示例
### 示例1：打印字符矩阵
```python
def printMatrix(row, col, symbol):
    for i in range(row):
        for j in range(col):
            print(str(symbol), end=" ")
        print()
```
- 功能：输入行数、列数、符号 → 输出字符矩阵
- 测试：printMatrix(3, 4, '*')

### 示例2：求和函数对比
| 带返回值 | 不带返回值 |
|---------|-----------|
| return s | print(s) |
| 结果可参与后续运算 | 仅在函数内打印 |

## 六、易错提醒
- `{}` 创建空字典，`set()` 创建空集合（函数同理）
- 函数体必须缩进，否则语法错误
- return 后的代码不执行
- 参数可以不写（无参函数）
- 默认参数必须在位置参数之后
